<h2><a href="https://www.geeksforgeeks.org/problems/gp-term/1">Nth Term of GP from First Two Terms</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given the first 2 terms <strong>a&nbsp;</strong>and <strong>b </strong>of a Geometric&nbsp;Series. The task is to find the<strong> n<sup>th</sup></strong> term<strong> </strong>of the series.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a = 2, b = 3, n = 1
<strong>Output: </strong>2
<strong>Explanation: </strong>The first term is already given in the input as 2</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a = 1, b = 2, n = 5
<strong>Output: </strong>16
<strong>Explanation: </strong>Common ratio = 2,Hence Fifth term is 1*(2)<sup>(5-1)</sup>&nbsp;= 2<sup>4</sup>&nbsp;= 16 .</span></pre>
